# Primary OCR engine (PaddleOCR 3.x API). paddlepaddle pinned per-platform:
# 3.1.1 is the newest wheel for macOS arm64 / Python 3.12; other platforms may
# use 3.x latest. paddleocr 3.7.0 pairs with paddlex 3.7.x.
#
# The [ocr-core] extra of paddlex is REQUIRED at runtime — without it
# PaddleOCR raises "OCR requires additional dependencies" when creating the
# pipeline and the chain falls back (flagged per image) to Tesseract.
# The extra pins opencv-contrib-python, which collides with
# opencv-python-headless on the `cv2` namespace; the Dockerfile installs
# libGL/libglib2.0-0 so either wheel can load cv2 at runtime.
